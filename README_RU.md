# ComfyUI Easy String Nodes (на русском)

Набор лёгких текстовых узлов для [ComfyUI](https://github.com/comfyanonymous/ComfyUI) без внешних зависимостей:

- выбор строк из нумерованного многострочного текста по **исходным** номерам;
- перевзвешивание элементов в синтаксисе `(тег:вес)`;
- выбор через **пресеты** и блокировка узла **триггером**;
- разделение строк на **позитивный / негативный** промпты;
- объединение промптов в один.

Все узлы — на чистом Python (только стандартная библиотека). Тесты запускаются без ComfyUI.

## Установка

### Через ComfyUI Manager (рекомендуется)
**ComfyUI Manager → Install Custom Nodes**, найдите `Easy String Nodes`, перезапустите ComfyUI.

### Вручную
```bash
cd ComfyUI/custom_nodes
git clone https://github.com/Ghost-in-the-dark/ComfyUI-EasyStringNodes.git
```

Перезапустите ComfyUI — все узлы появятся в категории **Text Processing**. Файл `pyproject.toml` добавлен, чтобы репозиторий можно было опубликовать в [ComfyUI Registry](https://docs.comfy.org/registry/).

## Синтаксис выбора строк

Поля `line_numbers` (и строки пресетов) понимают небольшой язык:

| Запись | Значение |
| --- | --- |
| `1` | строка 1 |
| `1,3` | строки 1 и 3 (в этом порядке) |
| `2-4` | строки 2, 3 и 4 (включительно) |
| `1,1` | строка 1 дважды (дубликаты сохраняются) |

Строка вида `N: содержимое` выбирается по **явному номеру N** (например, `10: кот` выбирается записью `10`). Строки без префикса `N: ` адресуются **позиционно** (с 1). Неизвестные токены и выбор, которому ничего не соответствует, дают понятную ошибку, а не пустой промпт.

## EasyString

Выбор строк из нумерованного многострочного текста и их объединение.

**Входы**

| Вход | Тип | По умолчанию |
| --- | --- | --- |
| `input_text` | STRING (многострочный) | нумерованные строки, напр. `1: кот` … |
| `line_numbers` | STRING | `1` |
| `add_break` | BOOLEAN | `false` |

**Выход:** `output_text` (STRING) — выбранные строки через пробел.

*Пример:* `1: кот` / `2: пёс` / `3: птица`, выбор `1,3` → выход `кот птица`. HTML (включая `<br>`, `<p>`, списки) сначала превращается в обычный текст с переносами строк, поэтому текст из браузера остаётся чистым.

## EasyStringV2

Как *EasyString*, но дополнительно разбивает каждую выбранную строку на элементы через запятую (запятые **внутри** `()`, `[]` и `{}` учитываются) и переписывает каждый элемент с весом.

**Входы**

| Вход | Тип | По умолчанию |
| --- | --- | --- |
| `input_text` | STRING (многострочный) | нумерованные строки |
| `line_numbers` | STRING | `1` |
| `weight` | FLOAT (слайдер 0.1–10.0) | `1.0` |
| `apply_weight` | BOOLEAN | `true` |
| `add_break` | BOOLEAN | `false` |

**Выход:** `output_text` (STRING)

Поведение:

- `apply_weight = true`: каждый элемент переписывается как `(текст:вес)`. Элемент с уже числовым весом — `(текст:1.5)`, `[текст:1.5]`, `{текст:1.5}` — сохраняет текст и скобки, но получает новый вес.
- `apply_weight = false`: элементы возвращаются очищенными как есть (скобки не добавляются).
- Порядок выбора сохраняется: `2,1` выведет строку 2 перед строкой 1.
- `add_break = true` добавляет ` BREAK`.

*Пример (apply_weight = true, weight = 1.2):* `1: кот, пёс`, выбор `1` → выход `(кот:1.2), (пёс:1.2)`.

## EasyStringSelector

*EasyStringV2* плюс **пресеты** и **вход-триггер**.

**Входы**

| Вход | Тип | По умолчанию |
| --- | --- | --- |
| `input_text` | STRING (многострочный) | нумерованные строки |
| `line_numbers` | STRING | `1` |
| `preset_input` | STRING (многострочный) | строки пресетов `1: …` |
| `use_preset` | BOOLEAN | `false` |
| `preset_line` | INT (1–100) | `1` |
| `preset_trigger` | BOOLEAN (вход) | `true` |
| `weight` | FLOAT (слайдер) | `1.0` |
| `apply_weight` | BOOLEAN | `true` |
| `add_break` | BOOLEAN | `false` |

**Выход:** `output_text` (STRING)

Пресеты работают как синтаксис выбора строк: каждая нумерованная строка `preset_input` хранит spec выбора, а `preset_line` выбирает активную. Пример файла пресетов:

```
1: 1
2: 1,3
```

При `use_preset = true` и `preset_line = 2` узел выберет строки 1 и 3 из `input_text`.

`preset_trigger` работает как **гейт**: при `false` узел выдаёт понятную ошибку вместо результата — удобно сознательно приостановить ветку графа. Подключается виджетом или от другого узла (вход с `forceInput`).

## EasyStringSelectorNeg

Выбирает строки как остальные узлы, но каждую выбранную строку делит по `---` на **позитивную** и **негативную** части, отдавая оба промпта отдельными выходами.

**Входы**

| Вход | Тип | По умолчанию |
| --- | --- | --- |
| `input_text` | STRING (многострочный) | `1: … --- …` |
| `line_numbers` | STRING | `1` |
| `preset_input` | STRING (многострочный) | строки пресетов |
| `use_preset` | BOOLEAN | `false` |
| `preset_line` | INT (1–100) | `1` |
| `preset_trigger` | BOOLEAN (вход) | `true` |
| `weight` | FLOAT (слайдер) | `1.0` |
| `apply_weight` | BOOLEAN | `true` |
| `add_break` | BOOLEAN | `false` |

**Выходы:** `positive_prompt` (STRING), `negative_prompt` (STRING)

Строка может содержать `позитив --- негатив`; часть до первого `---` идёт в позитивный выход, после — в негативный. Строки без `---` дают только позитивный элемент. Взвешивание работает как в *EasyStringV2* для обоих выходов.

*Пример (apply_weight = true, weight = 1.0):* `1: кот --- пёс` / `2: птица`, выбор `1,2` → позитив `(кот:1), (птица:1)`, негатив `(пёс:1)`.

## EasyStringNegEditor

Конструктор позитива/негатива в стиле *SelectorNeg* с **визуальным редактором строк**. Узел работает и на классическом (legacy) фронтенде ComfyUI, и на новом фронтенде на Vue.

У каждой строки есть: необязательный **исходный номер** (#), необязательная **категория**, **галочка** (чекбокс), **позитивный** промпт, **негативный** промпт и необязательная **картинка**. Новые и импортированные строки **создаются без галочки**. При включённом `select_checked` в вывод идут только отмеченные; при `select_all`=off и пустом `line_numbers` тоже берутся отмеченные галочкой строки. Если не выбрано ничего (нет отмеченных галочкой, пустой `line_numbers` или пресет/номера, которым ничего не соответствует), узел **не падает**, а просто выдаёт пустые строки — пустой выбор это нормальный результат «нет строк». Картинка — только помощник интерфейса: она показывается в превью при наведении на строку и никогда не попадает в API-промпт. **Без data-файла** картинка остаётся в JSON воркфлоу (уменьшенная, в виде data URL), и воркфлоу автономен. **В режиме data-файла картинка загружается один раз и хранится файлом** рядом с набором (`data/<имя>.img/...`), а строка держит только имя этого файла: JSON набора остаётся крошечным, и клик по галочке больше не пересылает и не перезаписывает все картинки (набор на 200 картинок раньше означал ~10 МБ записи на каждый клик). При сохранении старого набора, где картинки ещё лежат внутри строк как base64, они автоматически раскладываются в файлы — про это говорит янтарный бейдж **inline** на карточке строки.

**Категория** — произвольная текстовая метка (чип на строке), по ней список фильтруется в диалоге. **Галочка** на строке — ручной выбор: когда вход узла `select_checked` включён, в вывод попадают только отмеченные строки (это перекрывает `select_all` и пресеты). При включённом `preset_checked` та же галочка фильтрует **внутри пресета**: пресет тогда берёт только свои отмеченные строки, так что пресет можно подрезать, снимая галочки, а не правя список номеров. Рядом с каждым пресетом на узле (и на вкладке **Presets** в диалоге) у каждой строки, на которую ссылается пресет, стоит тот же чекбокс — оба места показывают и меняют один и тот же флаг.

**Входы**

| Вход | Тип | По умолчанию | Примечания |
| --- | --- | --- | --- |
| `rows` | STRING (JSON) | 2 демо-строки | `[{num?, cat?, on?, pos, neg, img, freq?}, …]`; редактируйте кнопкой **Add / Edit rows**, а не вручную |
| `presets` | STRING (текст) | пусто | один пресет на строку: `N: номера строк` (`1: 108 193 135`); редактируется/импортируется на вкладке **Presets** |
| `line_numbers` | STRING | `` (пусто) | какие строки брать, когда `select_all`, `use_preset` и `select_checked` выключены (`1,3` или `2-4`); пусто = строки, отмеченные галочкой; пустой результат даёт пустые строки |
| `select_all` | BOOLEAN | `true` | `true` = все строки, `false` = по `line_numbers` (или отмеченные галочкой, когда `line_numbers` пусто); пустой выбор даёт пустые строки |
| `use_preset` | BOOLEAN | `false` | `true` = использовать пресет из `preset_line` вместо выбора строк |
| `preset_line` | INT | `1` | какой пресет (по номеру) применять при `use_preset = true` |
| `weight` | FLOAT (слайдер) | `1.0` | вес элементов |
| `apply_weight` | BOOLEAN | `true` | переписать каждый элемент как `(текст:вес)` |
| `add_break` | BOOLEAN | `false` | добавить ` BREAK` к позитивному выходу |
| `preset_trigger` | BOOLEAN (опциональный вход) | `true` | опциональный гейт запуска — **не подключайте, чтобы узел всегда работал**; можно подключить `false`, чтобы заблокировать узел с ошибкой |
| `data_file` | STRING | пусто | имя файла набора в папке данных узла (напр. `artists.json`); когда задано, rows + presets загружаются из этого файла при выполнении, а воркфлоу хранит только имя |
| `select_checked` | BOOLEAN | `false` | `true` = только строки, отмеченные галочкой в редакторе (ручной выбор; перекрывает `line_numbers` и пресеты); ничего не отмечено — пустые строки на выходе |
| `preset_checked` | BOOLEAN | `false` | `true` = пресет берёт только те свои строки, что отмечены галочкой (пресет ∩ отмеченные); `false` = пресет берёт все свои строки независимо от галочек. Действует только при `use_preset` |

**Выходы:** `positive_prompt` (STRING), `negative_prompt` (STRING)

Строки ведут себя как строки `позитив --- негатив` в *EasyStringSelectorNeg*: текст строки делится на элементы через запятую (с учётом `()`/`[]`/`{}`), каждый элемент опционально перевзвешивается, позитивы собираются в позитивный выход, негативы — в негативный. Номер пресета выбирает строки с перечисленными номерами: каждый номер сначала ищет строку с таким **исходным #**, иначе берёт строку по позиции (с 1) в списке.

**Импорт старых данных**

Кнопка **↧ Import old data** (вкладка Rows) вставляет нумерованный набор — ровно формат старого *Easy String Selector Neg*, одна строка на строку текста, заканчивающаяся `~` — и превращает каждую строку в запись: номер сохраняется как **исходный #**, остальной текст уходит в выбранное поле (**Negative** по умолчанию). Строка в старом формате SelectorNeg `позитив --- негатив` делится по первому `---` верхнего уровня: часть до него становится полем **positive**, часть после - полем **negative** (любая из частей может быть пустой) - так старые наборы с негативным хвостом восстанавливаются правильно. Строки без `---` целиком попадают в выбранное поле. Вставляйте из буфера обмена или выбирайте файл `.txt`. Исходные номера сохраняются, поэтому пресеты и `line_numbers` продолжают указывать на те же строки даже после перестановок и правок.

**Пресеты**

Вкладка **Presets** правит поле `presets` напрямую (`номерПресета: номера строк`, например `7: 108 193 135`; работают пробелы, запятые и диапазоны вида `1,3 5-7`). **↧ Import presets…** вставляет целый блок. Чтобы выход управлялся пресетом, включите `use_preset = true` и выберите `preset_line` на узле.

**Как пользоваться редактором**

- Нажмите кнопку **✎ Rows / Presets — edit** на узле, чтобы открыть диалог.
- Вкладка **Rows**: строка поиска, **фильтр по категориям** (у каждого пункта видно число строк; новая категория, введённая в поле `Cat:` карточки, сразу становится доступной для выбора, перезапуск диалога не нужен), **+ Add row**, **↧ Import old data** и кнопки массового переключения **Tick all / Untick all** — они действуют на строки, которые диалог сейчас показывает, а число этих строк стоит прямо в подписи кнопки (`Tick all 12`); клик по карточке открывает её галочку, категорию, поля, исходный номер (#), картинку, порядок (↑/↓) и удаление (🗑). При большом числе строк диалог отрисовывает только видимую часть списка и дорисовывает по мере прокрутки, поэтому он открывается мгновенно даже для огромных наборов. Из-за этой оконной отрисовки **+ Add row** вставляет новую строку **сверху** и сразу ставит курсор в её первое поле: она тут же на экране, прокручивать ничего не нужно, а поиск и фильтр по категориям сбрасываются, чтобы новая (пустая) строка не была отфильтрована. При этом каждая существующая строка сохраняет свой **# (orig)**, поэтому пресеты и `line_numbers` адресуют ровно те же строки, что и раньше.
- Галочка на самом узле (в начале строки) тоже переключает строку. Длинные наборы листаются прямо на узле колесом мыши, стрелками **▲ / ▼** под списком или **перетаскиванием ползунка** справа от списка строк (когда список пресетов длиннее 4 строк, колесо листает и его).
- **Поиск прямо на узле**: маленькое поле под заголовком фильтрует строки по номеру, категории или тексту (`pos`/`neg`) на лету — заголовок показывает *Rows (найдено/всего)*, несовпавшие строки скрываются, крестик в поле очищает фильтр. Работает так же, как поиск в диалоге. Поиск, фильтр *only* и фильтр по категории — три независимых фильтра, которые складываются по И, и массовые кнопки всегда действуют на результат этого пересечения.
- **Кнопки прямо на узле**: под поиском пять кнопок — **all** (отметить), **none** (снять), **only** (показывать только отмеченные), **cat** (открыть список категорий) и **use** (порядок по частоте использования). Кнопки отметки действуют на строки, которые сейчас показывает список (поиск + *only* + категория, по И), а число затрагиваемых строк рисуется бейджем в правом верхнем углу кнопки, поэтому счётчик читается и на узкой ноде. Цвет нигде не является единственным носителем смысла: подсветка всегда дублируется подписью, нарисованной иконкой и бейджем.
- **Строка состояния**: под кнопками всегда видно, на что вы смотрите — `ticked 12 / 569` в обычном режиме и `showing 3 / 569 · cat artists + "portrait"` при активных фильтрах, так что число в заголовке и список под ним не могут разойтись. Если включить **only**, когда отмечены все строки, узел скажет об этом и предложит тут же нажать **✗ none**.
- **Список категорий**: кнопка **cat** показывает все категории с числом строк (и пункт *All categories* для сброса). Тот же список есть в селекторе категорий в диалоге, и оба вида делят одно состояние фильтра. Активный фильтр показан чипом в строке состояния: клик по этому чипу (или по чипу категории на строке) сбрасывает фильтр; клик по чипу строки — включает фильтрацию по этой категории.
- **Рейтинг по частоте**: у каждой строки есть скрытый счётчик `freq`, который узел увеличивает на 1 за каждый запуск, где строка реально попала в выбор (`select_all`, `line_numbers`, пресет или отмеченная галочка). Использованные строки подсвечиваются тёплым тоном и показывают счётчик **×N** справа. Кнопка **⇅ use** на узле сортирует только *отображение* по частоте (самые используемые сверху; повторный клик возвращает сохранённый порядок) — она никогда не переставляет сами строки, поэтому после перезагрузки воркфлоу список не «застревает» отсортированным. В диалоге кнопка **⇅ by use** намеренно переставляет рабочий список (нажмите **Save**, чтобы сохранить новый порядок), а **↺ # order** возвращает исходный порядок по номерам строк, чтобы отменить случайную сортировку по частоте. Счётчики сохраняются в воркфлоу/файле, так что рейтинг переживает перезагрузки.
- На узле под строками рисуется панель **Presets** (как в старом *Easy String Selector Neg*): виден список пресетов, активный подсвечен, а когда пресет не выбран — надпись `preset off — all rows / line_numbers mode`. Прямо там можно включить режим пресета кнопкой **use:on/off** и выбрать пресет кнопками **◀ / ▶**, либо кликнуть по строке пресета или по заголовку панели — откроется диалог на вкладке **Presets**.
- Вкладка **Presets**: строки `N: номера строк` можно ввести или импортировать.
- Вкладка **Data file**: сохраните весь набор (rows + presets) в файл `.json` в папке данных узла (**`ComfyUI-EasyStringNodes/data`**): введите имя (напр. `artists.json`) и нажмите **Save to file**, либо кликните по существующему файлу, чтобы загрузить его. Когда имя файла задано, воркфлоу хранит только его - строки лежат на диске и могут использоваться сразу в нескольких воркфлоу. Кнопка **Save** внизу тоже перезаписывает файл, если имя задано.
- **Save** сохраняет строки и пресеты (включая введённые на вкладке Presets) в скрытые виджеты `rows`/`presets` в обычном режиме или в файл набора в режиме data-файла; **Cancel** (или Esc) отменяет изменения.
- При наведении на нарисованную строку появляется плавающее превью с картинкой строки (если она есть).

> Скрытые поля, хранящие `rows` и `presets`, сохраняют стандартные имена виджетов, поэтому воркфлоу, копирование/вставка и API-промпт работают как обычно. Кастомный список виджетов в API-промпт не попадает. В режиме файла (`data_file` задан) виджеты rows/presets намеренно остаются пустыми - воркфлоу несёт только имя файла, а узел читает его при выполнении; отсутствующий или битый файл даёт понятную ошибку с именем файла.

## ConcatenatePromptsNode

Соединяет **подключённые** промпты в одну строку через пробел. Входы опциональные: в вывод попадают только подключённые, в числовом порядке (`prompt_2` раньше `prompt_10`).

**Входы (опциональные):** `prompt_1` … `prompt_20` (STRING, многострочные). Пустые и неподключённые пропускаются.

**Выход:** `concatenated_prompt` (STRING)

Чтобы изменить доступное количество, отредактируйте `MAX_INPUTS` в начале `Concatenate_prompts.py` и перезапустите ComfyUI.

## EasyStringTokenGraph

Показывает, какие токены вы действительно используете — и какие используете **вместе**. Текст проходит через узел без изменений, поэтому его можно поставить в любую существующую цепочку промпта: он только наблюдает.

Дайте узлу текст — он посчитает каждый токен, запомнит счётчики между запусками и нарисует их в виде **плавающего графа**: размер точки — как часто токен используется, линия — два токена встречаются рядом в одном промпте. Наведите на токен, чтобы увидеть, с чем он используется.

**Входы:** `text` (STRING, многострочный), `stats_file`, `reset`, `window`, `top_n`, `min_count`, `exclude`, `position`
**Опционально:** `text_in` (STRING, заменяет `text`, если подключён и не пуст), `trigger` (BOOLEAN)
**Выходы:** `text` (вход без изменений), `report` (JSON с рейтингом и именем файла статистики)

### Панель

| Элемент | Что делает |
| --- | --- |
| двойной клик по узлу или **show graph** на самом узле | открыть / закрыть плавающую панель |
| перетаскивание заголовка панели | перемещение; `Esc` закрывает |
| селектор `floating` / `top` / `bottom` / `left` / `right` | прикрепить панель к краю окна |
| **live** | учесть текст, который сейчас в поле узла, ещё до запуска очереди |
| **exclusions** | редактировать список токенов, скрытых из рейтинга |
| **reload** | перечитать накопленную историю с сервера |

Наведение на токен — в графе или в списке справа — приглушает всё не связанное с ним и открывает справку: сколько использований, в скольких запусках и **с какими токенами он используется**, отсортированными по силе связи. Параметр `window` задаёт, на каком расстоянии токены ещё считаются связанными; `1` — только непосредственные соседи.

### Токены качества

Шаблонные токены вроде `best quality`, `masterpiece`, `8k` или `highly detailed` есть в каждом промпте, поэтому они всегда занимают верх рейтинга и ничего не сообщают. По умолчанию они исключены: они по-прежнему считаются (ничего не удаляется, и они попадают в выход `report`), просто не показываются в рейтинге и на графе.

Список `exclude` сравнивается с токеном целиком, поэтому `detailed` скрывается, а `detailed eyes` и `detailed background` — это содержание, они остаются. `*` и `?` — подстановочные знаки, так что `year *` покрывает `year 2022` … `year 2024`. Правка списка в панели действует сразу на панель и при следующем запуске — на узел.

### История

Счётчики хранятся в `data/token_stats/<stats_file>.stats.json` и накапливаются между запусками, поэтому чем дольше вы работаете, тем полезнее граф.

- Оставьте `stats_file` **пустым**, чтобы считать только в памяти: на диск ничего не пишется, счётчики сбрасываются при перезапуске ComfyUI.
- Поставьте `reset` в `true` на один запуск, чтобы очистить счётчики этого файла перед ним.
- Статистика лежит в отдельной папке и никогда не показывается как датасет.

### Замечания

- Для каждого токена ведётся два числа: **uses** (всего вхождений) и **runs** (в скольких промптах он встречался). Пять вхождений внутри одного промпта — это один запуск, и эти числа отвечают на разные вопросы, поэтому показаны оба.
- Токены сворачиваются при подсчёте: `HDR_Photo`, `hdr-photo` и `HDR Photo` — один токен, отображается в том написании, которое встретилось последним.
- Подсчёт происходит в `IS_CHANGED`: он вызывается на каждую очередь, но не трогает виджеты, поэтому не меняет сигнатуру кэша узла и не заставляет пересчитываться узлы ниже по графу.
- Панели нужен собственный токенизатор — она пересчитывает рейтинг по тексту, который вы ещё набираете; тест на паритет удерживает его идентичным питоновскому.

## Тесты

```bash
cd ComfyUI-EasyStringNodes
python3 tests/test_nodes.py          # логика узлов
python3 tests/test_token_graph.py    # подсчёт токенов, исключения, один запуск — один подсчёт
python3 tests/test_token_parity.py   # паритет токенизаторов python и javascript (нужен node)
node tests/canvas_balance.mjs        # баланс состояния canvas (фронтенд узла)
node tests/tg_canvas_balance.mjs     # баланс состояния canvas (граф токенов)
node tests/tg_layout_test.mjs        # детерминизм раскладки, границы, попадание курсором
node tests/tg_exclude_hidden.mjs     # поле exclude сворачивается, не теряя значение
node tests/tg_widget_click.mjs       # кнопка "show graph" на узле реагирует на клик
node tests/esn_add_row.mjs           # "+ Add row" ставит строку туда, где её видно
```

`tests/canvas_balance.mjs` прогоняет виджет узла через все состояния отрисовки (строки, пресеты, фильтры, поповер категорий, свёрнутые настройки) с записывающим 2D-контекстом и проверяет один инвариант: **глубина стека состояний контекста после `draw()` равна глубине до него**. Виджет рисует на общем canvas ComfyUI, поэтому `ctx.restore()` без парного `ctx.save()` снимает кадр состояния, который отрисовщик графа сохранил для себя; все узлы и связи, нарисованные после этого, получают чужие `fillStyle`, `globalAlpha` и потерянный трансформ и рисуются пустыми или чёрными плитами. Проверка через `grep -c ctx.save()` этот баг не ловит (те же слова есть в комментариях), поэтому проверка поведенческая. Обе команды не требуют сторонних пакетов и браузера.

`tests/tg_canvas_balance.mjs` дополнительно падает, если две подписи рисуются на одной базовой линии или за пределами полосы: полоса токенов рисуется в ту высоту, которую дал ComfyUI, а узел, растянутый вручную, может дать заметно меньше, чем запрашивает `computeSize()`. Две подписи на одной строке — это баг отрисовки, даже если баланс save/restore идеален.

`tests/tg_widget_click.mjs` вызывает `draw()` и `mouse()` с одним и тем же началом координат, как это делает фронтенд, и проверяет, что кнопка "show graph" действительно переключает панель. Эти две точки входа используют **разные системы координат**: в `draw()` приходит верх виджета в координатах узла, а в `mouse()` — позиция в той же системе. Полоса токенов одно время проверяла попадание так, будто `pos` уже отсчитан от виджета. В результате кнопка отрисовывалась идеально и ничего не делала при клике, а тесты этого не ловили, потому что `mouse()` не вызывался нигде.

`tests/esn_add_row.mjs` открывает настоящий диалог строк и нажимает настоящую кнопку **+ Add row**. Список отрисовывается окнами по 60 карточек, поэтому прежний `rows.push` отправлял новую строку за пределы отрисованного окна: её карточки не существовало, вызов фокуса ничего не делал, а `list.scrollTop = list.scrollHeight` доходил лишь до низа этого окна. На списке из 2000 строк новая строка оказывалась на 10211px ниже видимой области, и фокус был нигде. Тест воспроизводит ровно эту ситуацию (контейнер с прокруткой, содержимое которого выше его окна, и `innerHTML = ""`, сбрасывающий фокус внутри) и проверяет, что строка оказывается первой, видимой, в фокусе и сохраняется первой — при этом каждая существующая строка сохраняет свой **#**, по которому её адресуют пресеты. Браузер не нужен.

`tests/tg_exclude_hidden.mjs` покрывает вход `exclude`. Его значение по умолчанию — список из пятидесяти строк, а ComfyUI задаёт многострочному виджету высоту примерно по содержимому, поэтому видимый `exclude` резервировал сотни пикселей тела узла. Узел сворачивает его (так же, как `EasyStringNegEditor` прячет свои служебные виджеты), и тест проверяет обе половины: высота действительно становится нулевой, а значение остаётся доступным для чтения и записи через панель исключений.
